## 2. 填表用伤害口径

不修改设计文档中的机制叙述；填血量与 `damage` 时统一按：

```
对敌命中扣血 = max(1, Event.damage)
对己受击扣血 = max(1, attackPower)    // 规划期 armor = 0
```

- `count`：命中次数（或一次结算等价于 `最终扣血 × count`）
- 管道对 `Event.damage` 的加减，体现在各器官已写明的 `damage` 字面值上
- DoT / 控制 / 暴击等：设计保留；本规划**不另开乘区表**，相关细数标「沿用设计 / Demo 后补」
