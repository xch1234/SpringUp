# 潮涌之躯（SpringUp）

本次器官目录整理：[六项修改与持续效果说明](Docs/器官资源整理与持续效果说明.md)。逐个查脚本和器官：[程序 A 脚本逐项说明与器官对照](Docs/程序A脚本逐项说明与器官对照.md)。

Unity 2D 器官组合游戏。当前主流程：战斗 60 秒 → 获得奖励 → 休息期装配器官 → 下一波，共 7 波。更新：2026-10-17。已整合 main 的独立场景、商店与经济系统，详见 [main 与 A 整合记录](Docs/2026-10-17-main与A整合记录.md)。

## 第一次打开

1. 用 **Unity 6000.5.11f1** 打开工程，等待资源导入与脚本编译。
2. 打开 **`Assets/Scenes/Flow/Bootstrap.unity`**，点击 Play，再点击“开始新局”。
3. WASD / 方向键移动，Shift 疾跑。**器官自动攻击，不需要按 F，也没有玩家攻击充能。**
4. 左上角查看装备，点击“伤害 / 触发记录”查看本波反馈。
5. 按 B / Tab 打开背包；战斗时只读，休息时可安装、替换、拆下和丢弃。休息时靠近青绿色商人按 E 购买或出售，再点击下一波。Esc 逐层关闭窗口或暂停。

头、手、腿各 6 个普通槽位，普通器官可跨部位装配；躯干 2 个专用槽位。三条管道各自循环，默认槽位间隔 0.15 秒、整轮周期 2 秒。静止充能触发器与大激光自身蓄力仍保留。

## 我想改数值

先停止 Play，再修改 Inspector 并保存；运行中改变的值通常不会保留。

- **攻击快慢、玩家基础属性**：`Flow/Battle.unity` 和 `Flow/Rest.unity` 中 `World/Player → PlayerStatsBase`（两份场景分别保存；旧 Demo 有自己的配置），节奏看 `Base Cooldown` 和 `Base Cycle Duration`。
- **19 种执行器**：`Assets/Data/Organs/Actuators/*Behaviour.asset`。
- **10 种触发器（9 种条件）**：`Assets/Data/Organs/Triggers/*Trigger.asset`。
- **7 种躯干**：`Assets/Data/Organs/Torso/*Torso.asset`。
- **独立状态参数**：`Assets/Data/Statuses/`。原 Hand 中六种执行器已迁入 Actuators，多肢触手迁入 Triggers，普通器官不限制头/手/腿部位。
- **敌人数值、行为与击杀骨髓**：`Assets/Data/Enemies/`；迁移差异与验收见 [敌人配置与击杀骨髓迁移](Docs/敌人配置与击杀骨髓迁移.md)。前六波生成截止时间在 `Assets/Data/Waves/SpawnSettings.asset`。
- **波次时长和器官奖励**：`Assets/Data/Waves/waves.json`。库存价格等元数据在 `Assets/Data/Organs/organs.json`；实际战斗数值来自器官 `.asset`。

逐项参数、脚本示例和场景对象位置见 [开发改动总览与调参手册](Docs/开发改动总览与调参手册.md)。不要寻找已删除的 `mvp_baseline.json` 或充能组件。

## 我想试新器官

主场景进入休息期后，使用 **Tools → SpringUp → 样板** 菜单添加执行器、触发器或躯干，再从背包装入槽位。新增样板尚未全部加入正式掉落表；背包超容量时需装备、出售或丢弃后再出战。

## 场景分别做什么

- **Flow/Bootstrap**：当前完整试玩与构建入口，加载主菜单、战斗、休整；不要单独 Play Battle / Rest。
- **SpringUpDemo**：保留的旧整合流程与回归入口，已同步 C 的新版 40×40 平铺地图、相机、边界墙及移动碰撞；不包含新商店界面。
- **LaboratoryDemo**：独立器官装配与效果预览，包含全部 36 种配置；使用临时样例库存。
- **OrganDemo**：旧七器官的预设演示，也是回归检查使用的场景。
- **Battle_Greybox**：程序 C 的战场源场景，用于地图、敌人和移动调试，以及向 Demo 同步战场。这里的 F 是开发伤害快捷键，不是主场景的玩家攻击。

旧的 `Scenes/Tests` 七个重复演示已删除。`Assets/Tests/Editor` 是仍在使用的自动化检查，不是废弃文件。

## 当前范围与验证

已有 19 种执行器、10 种触发器、7 种躯干，共 **36 种战斗定义**。支持自动攻击、装备连锁、敌人受伤闪色、伤害记录、七波结算、失败与重开。

完整“同一次攻击沿管道逐级改造”、Boss、旧蜘蛛巢和躯干升级仍未完成。新商店现在提供 4 个休整期商品（锈刀固定保留，其余随机刷新），并支持未装备库存出售；每波器官奖励也从对应随机池抽取。第六波蜘蛛巢奖励临时映射成 TNT；第七波目前是计时通关。

配置检查和回归入口见 [工程配置操作单](工程配置操作单.md)。自动化流程会加速结束波次，不能替代完整七波平衡试玩。最新隔离验证使用本机缓存 URP 17.5.0，工程声明为 17.6.0；正式依赖与目标设备上的发布构建仍需验收。
