# 潮涌之躯（SpringUp）

> Unity 工程说明：本文记录当前文件夹的实际用途、团队职责和后续安排。目录说明会区分“已经存在”和“建议后续建立”。

## 项目简介

《潮涌之躯》是一款以器官组合和自动战斗为核心的 2D 游戏。玩家在波次之间调整器官组合，观察触发器和执行器产生的连锁效果。当前策划方向为 7 个波次、头/手/腿 3 条器官管道（每条 6 个槽位）、躯干专属器官，目标器官总数为 43 个。玩法规则以[策划案](策划案.md)为准，程序数据和调用约定参考[接口草案](接口草案.md)。

## 当前工程状态

当前目录是 Unity 2D URP 工程，含 Unity 默认示例场景、渲染和输入设置。检查时还没有发现玩法脚本、自制预制体、器官数据或正式美术资源，因此目前属于工程骨架阶段。下方标为“建议”的目录尚未创建。

### 建议后续建立的 `Assets/` 目录

以下是建议结构，当前并非都已存在。按功能逐步创建即可，不必为目录齐全而建立空文件夹。

```text
Assets/
├─ Scenes/                 # 正式场景：实验室、战斗、主菜单等
├─ Scripts/
│  ├─ Core/                # 事件、公共数据、游戏状态等基础代码
│  ├─ Organs/              # 器官配置、触发器、执行器和管道逻辑
│  ├─ Player/              # 玩家移动、属性和身体部位
│  ├─ Enemies/             # 敌人、状态效果、受伤与死亡
│  ├─ Systems/             # 波次、掉落、背包、商店、存档等
│  └─ UI/                  # 界面交互与显示
├─ Prefabs/                # 可复用对象：玩家、敌人、器官图标等
├─ Data/                   # 器官 JSON 或 ScriptableObject 配置
├─ Art/                    # 图片、动画、材质、特效等美术资源
├─ Audio/                  # 音乐和音效
└─ UI/                     # 字体、界面图片等 UI 资源
```

代码和资源通过 GitHub 共享；不要提交 `Library/`、`Temp/` 等缓存。Unity 资源旁的 `.meta` 文件应和资源一起提交，不要单独删除。多人协作前约定分支、提交和冲突处理方式。

## 职位工作划分

以下职责依据新版“3 条管道、躯干特殊器官、43 个器官”方案整理。角色名是职责标签，团队可补充成员姓名；每个模块要有一位主负责人。

| 角色 | 主要工作 | 交付及协作 |
| --- | --- | --- |
| 程序 A：战斗与器官核心 | 定义战斗事件；实现头/手/腿三条 6 槽管道、游标执行、触发器/执行器、伤害和状态传递、连锁深度限制及触发反馈。 | 先交付一个执行器、一个修改执行器的器官、一个触发器组成的最小闭环；与 B 对接安装预览，与 C 对接玩家/敌人事件。 |
| 程序 B：实验室与战斗 UI | 显示 18 个管道槽位和器官信息；实现查看、拖放/替换、执行预览、触发反馈。 | 初期可用模拟数据搭界面，后续接入 A 的管道/预览接口和 D 的背包；躯干器官槽数量待策划确定。 |
| 程序 C：玩家、敌人与战场 | 实现玩家移动和属性运行时；敌人 ID、生命、受伤、状态、死亡事件；基础敌人 AI、临时地图和战斗波次支持。 | 向 A 提供受伤、击杀、状态施加等事件；与 D 对接波次开始/结束和敌人生成。 |
| 程序 D：数据、流程与经济 | 实现器官数据读取/校验和样例数据；连接波次、掉落、背包（草案上限为 5）、商店、货币和躯干成长。 | 与策划维护器官数据、稀有度和花费；确保第一波能获得可组合的器官。 |
| 美术 A：角色与器官资源 | 玩家头/手/腿表现、占位角色和敌人、器官图标规范与图标、常规敌人和 Boss 资源。 | 先提供统一规格的占位资源，支持程序联调，再逐步补正式资源。 |
| 美术 B：场景与界面表现 | 深海地图灰盒和氛围、界面视觉资源、特效样式模板及战斗反馈表现。 | 优先支持实验室和第一张战斗地图清晰可读，再丰富细节。 |
| 策划/统筹 | 维护唯一有效的规则版本；完善 43 个器官的效果、部位、触发条件、目标和参数；确定数值、教学与验收流程。 | 决策同步到策划案、接口草案和任务拆解。现有资料提到 4 名程序+2 名美术，同时又单列策划职责，请团队确认策划由谁兼任，避免无人负责。 |

5. 当前工程尚无玩法实现，时间紧时先做完 M1，不要同时铺开全部 43 个器官的精细实现。
