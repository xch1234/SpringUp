# 范围器官表现与整波刷怪

## 三种简易效果

- TNT：黄白中心闪光、橙色扩散圈，在实际爆炸中心播放，扩散至实际爆炸半径，默认 0.3 秒淡出。伤害仍在原时机即时结算。
- 毒雾：绿色透明雾区、四个缓慢漂动的圆斑与范围边界。读取实际执行器位置和半径，执行结束或清场时消失，不重复叠加旧通用线框。
- 坍缩体：深紫中心、两条旋转向内卷曲的弧线，读取实际吸引半径和持续时间。同一器官再次发动时替换旧表现。

所有动画使用游戏时间，暂停时冻结。范围和伤害仍由器官配置决定，表现层不造成伤害或改变吸引逻辑。

调整 `Assets/Resources/AreaEffectVisualSettings.asset`：

| 参数 | 用途 |
| --- | --- |
| Explosion Color / Flash Color | TNT 扩散圈和中心闪光颜色，A 控制透明度 |
| Explosion Seconds | TNT 表现时长，不延迟伤害 |
| Fog Color / Fog Animation Speed | 毒雾颜色、透明度和漂动速度 |
| Hole Color / Swirl Color | 坍缩体中心及弧线颜色 |
| Hole Animation Speed | 坍缩体旋转速度 |
| Line Width / Sorting Order | 线宽及显示层级 |

圆形软边图案运行时生成，无额外图片或美术素材依赖。共享纹理和材质随表现组件销毁释放，效果实例在结束或清场时销毁。停止 Play 后修改配置，再开局查看。

## 整波刷怪

所有波次的刷怪窗口等于实际波次时长，60 秒波次的最后十秒也允许预约生成。存活上限、动态刷怪倍率、累计减速和出生水花仍生效，因此不保证每秒都有新敌人。

主刷怪与兵工厂使用共享预约入口。波次结束或下一波开始时，清除未完成的出生水花并失效旧回调，防止休整时或下一波出现旧波敌人。

自动累计减速阈值按完整刷怪时长计算；手动填写的阈值保持原值。整波生成量可能随之增加。

`WaveSpawnSettings.firstSixSpawnSeconds` 仅保留旧资产／工具兼容，已隐藏且不再影响生成。修改它不会缩短刷怪窗口。
