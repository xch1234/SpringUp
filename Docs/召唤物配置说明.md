# 召唤物配置说明

图片为 `Assets/Art/Organs/summon_follower.png`，对应器官 ID `summon_follower`。保留 5 列×2 行的 10 帧动画。`organs.json` 的 `icon_sprite` 指定 `summon_follower_0` 作为商店、背包、装备栏图标。

装配后立即在玩家身边出现，跟随玩家并根据移动方向翻转。每个器官实例只保留一个存活召唤物，卸下或离开当前场景会清理；死亡后可由该器官下一次执行重新召唤。触发器控制的槽位在首次装配生成后，需再次满足触发条件才能重新召唤。

## 战斗与触发

- 接触敌人造成伤害，同时按该敌人的攻击力扣除召唤物生命。即使这次接触杀死敌人，也结算本次碰撞承伤。
- 同一敌人按碰撞间隔重复结算，不会每个物理帧扣血；敌人有多个碰撞体也只结算一次。
- 被敌人子弹击中时，扣除子弹的伤害并消耗子弹。根据弹道上先后顺序判断玩家或召唤物谁先被击中，一发子弹只伤害一个单位。
- 按槽位相邻连接：`召唤物 → 命中触发 → 执行器` 或 `召唤物 → 受伤触发 → 执行器`。命中使用实际造成伤害事件；受伤使用敌人碰撞、敌弹等外部伤害事件。
- 后续执行器从召唤物位置发动，并以召唤物为中心索敌。继续连接的触发链、延迟执行和环绕效果也保留该主体；召唤物死亡或移除后不再从它发动后续攻击。
- 玩家的受伤不会误触发接在召唤物后的受伤器官。召唤物自然生命衰减不触发受伤；每次新的碰撞或受击会建立新的触发链。
- 暂停窗口会暂停跟随、动画、碰撞结算、子弹和生命衰减。

## 数值参数

在 Unity Project 中选择 `Assets/Data/Organs/Actuators/SummonBehaviour.asset`，在 Inspector 修改：

- `Damage`：碰撞基础伤害，暂设 **5**，可继续调整，实际伤害沿用角色攻击加成等战斗规则。
- `Hit Radius`：圆形碰撞半径，默认 **0.35** 世界单位。
- `Interval`：同一敌人的碰撞结算间隔，默认 **0.5 秒**。
- `Health`：生命上限，默认 **20**。
- `Health Decay`：每秒自然损失生命，保留原默认 **2**；设为 **0** 可关闭自然衰减。
- `Speed`、`Follow Distance`：跟随速度、距离，默认 **4**、**1.8**（跟随距离已从 0.8 调远）。

敌人碰撞承伤取敌人配置的 `Attack Power`；敌弹承伤取子弹伤害。运行时战斗参数以该行为资源为准，`organs.json` 保留器官 ID、图标及基础数据对应关系。

外观参数在 `Assets/Resources/SummonVisualSettings.asset`：帧序列、帧率（默认 10）、显示宽度（默认 1.4 世界单位）和左右翻转。

召唤物头顶显示红色血条，按当前生命 / 最大生命从右向左缩短，受击和自然衰减都会更新。血条随召唤物移动，死亡或卸下时一起移除。在外观配置的“头顶血条”分组中，可修改显示开关、相对贴图顶部的偏移、宽高、血条颜色和底色（颜色 Alpha 可调透明度）。
