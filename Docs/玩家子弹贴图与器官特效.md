# 玩家子弹贴图

配置入口：**Tools → SpringUp → 玩家子弹 → 编辑贴图与动画**。
资源：`Assets/Resources/ProjectileVisualSettings.asset`。

- 环绕子弹使用 `Assets/Art/Items/子弹.png` 的金色球体，在执行器原有环绕位置显示。
- 直线、螺旋、追踪和三连发使用 `Assets/Art/Items/发射子弹.png` 的 5 帧循环动画，拖尾随实际飞行方向旋转。
- 原图不改动；通过导入切片去掉大面积透明留白，逐帧把旋转中心对齐金色弹头。环绕图中的孤立小碎片不作为动画帧。
- 可调整帧图片、帧率、弹头像素直径、显示大小倍数、颜色与透明度、方向修正和显示层级。默认显示直径为碰撞直径的 1.5 倍。
- 仅修改外观，伤害、弹速、寿命、索敌、环绕距离和碰撞大小仍使用原配置。暂停时动画停止；弹体结束后回收显示对象，场景退出时清理。

## 仍缺少专用战斗贴图的器官特效

检查范围：实际执行器与 `BattleOrganEffects` 渲染路径，以及当前 `Assets/Art` 资源。背包里的器官图标不代表其战斗特效已使用贴图。

- **激光、蓄能激光**：灰色蓄力线／青色光束，使用 LineRenderer，缺少光束、蓄力和命中素材。
- **毒雾**：绿色半透明圆环，缺少毒雾范围动画。
- **吸血针**：黄色弹体圆环，缺少针状飞行与命中素材。
- **章鱼吸盘**：紫色弹体／附着圆环，缺少飞行和附着动画。
- **导弹**：黄色飞行圆环、橙色爆炸圆环，缺少专用导弹及爆炸素材。
- **孢子**：绿色圆环，缺少漂浮孢子素材。
- **TNT**：橙色范围圆环，缺少爆炸动画。
- **坍缩体（黑洞）**：蓝色范围圆环，缺少旋涡／吸附动画。

此外，拳头、钢管、锈刀、黏液腺目前走单目标直接伤害路径，没有独立的挥击或命中特效；它们不属于已有色块待替换的情况。

召唤物已使用精灵帧动画，头顶血条为程序绘制的状态 UI。敌人出生和敌人子弹已有自己的图片资源。当前没有发现可直接匹配上述缺失特效的专用战斗动画；`Assets/Art/Organs` 中相应静态图片主要用于器官图标。
