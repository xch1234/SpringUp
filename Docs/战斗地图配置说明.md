# 战斗地图：随机地砖、大小与视野

配置文件：`Assets/Data/Maps/BattleMapSettings.asset`。

在 Unity Project 窗口选中它，或使用菜单 **Tools → SpringUp → 战斗地图 → 选择地图与视野配置**。正式入口 `Assets/Scenes/Flow/Bootstrap.unity` 使用这份配置，休整船不受影响。

## 给原 5.png 的位置加入随机外观

1. 将另外两张正方形图片放到 `Assets/Art/bk1440-s/`（文件名不限，不要覆盖四边和四角）。
2. 在图片的 Inspector 将 **Texture Type** 设为 **Sprite (2D and UI)**、**Sprite Mode** 设为 **Single**。像素图建议 **Filter Mode = Point**、**Compression = None**，然后点 Apply。
3. 选中地图配置，展开 **随机图片列表**，添加三项，分别拖入原来的 `5.png` 和两张新图。

每一个中间格独立、等概率选择一张图片。允许相邻格相同，不保证三种图数量完全相等。列表可放任意数量的图；空项会跳过，全部为空时回退到原 5 号图。图片应采用能相互拼接的正方形素材；不同尺寸 / Pixels Per Unit 会统一缩放到单格大小。四角与四边继续使用 1–9 九宫格对应图片，不参与中间格随机。

默认每次进入战斗（包括下一波重新加载 Battle 场景）重新随机；生成后不会每帧变化。取消 **每次进入战斗重新随机**，即可用 **固定种子** 重现布局。视觉随机数独立，不会消耗掉落、商店和刷怪的随机数。

当前配置仅包含现有的 `5.png`，添加新图片后才会出现多种外观。

## 地图大小

- **横向格数 / 纵向格数**：包含四边和四角；各支持 3–200 格。
- **每格边长**：世界单位，最小 0.5。默认 1.8。
- 实际地图宽度 = 横向格数 × 每格边长，高度同理；Inspector 会显示计算结果。

例如默认 40×40 格、每格 1.8，得到 72×72 地图。改为 60×40 格，则为 108×72；地砖自身不拉长。地图背景、四面边界墙、相机移动边界、刷怪范围与逃跑型敌人的边界限制会一起更新。

地图尺寸和图片列表在**下次进入战斗**时应用。编辑模式下 Scene 视图仍显示原来的烘焙地图；从 Bootstrap 进入 Play 后可看到实际生成结果。格数越多，生成和渲染的开销越大。

## 玩家视野

**基础视野半高** 默认 10.125，表示屏幕可见高度的一半。可见宽度取决于窗口宽高比。比如半高 10、窗口 16:9，大约能看到宽 35.56、高 20 个世界单位。

数值增大：看得更远，人物在画面上更小；数值减小：镜头更近。器官提供的视野倍率继续在此基础上叠加，例如 1.2 倍器官会将半高 10 变为 12。

运行中修改配置的基础视野会立即反映到战斗和休整区相机，躯干器官的视野倍率在两个场景均继续叠加。休整区使用船只场景，但视野数值仍来自同一份地图配置。战斗地图小于整个视野时，相机会居中，屏幕可能露出地图外区域；可减小视野或增大地图。请在停止 Play 后确认配置值，ScriptableObject 资源的修改可能保留到运行结束后。
