# 商店界面

从 Bootstrap 开局，进入休整区并靠近商店柜台，用当前交互键打开。Esc 或鼠标右键关闭；打开时世界暂停。

## 布局与操作

- 上方四件商品：点击看详情，右侧“购买”按钮完成交易。价格只显示数字，骨髓不足时变红并禁用购买。
- 下方背包：每页十四格，只显示未装备器官；点击后右侧操作变为“出售”。无拖动、装配、卸下或返回按钮。
- 右侧详情：图标、名称、类型、可滚动说明、交易价格和大尺寸操作按钮。缺图时显示器官名称。
- 顶部余额：`Assets/Art/Items/marrow.png` 图标与当前数值。
- 刷新按钮显示下一次刷新费用，余额不足时禁用。首次费用及递增规则沿用 RunController。

购买后商品显示“已售出”，保持商品选中，背包翻到新物品所在页。出售后清空选择，避免连续点击误卖下一件。同波重开不刷新商品。售出价格沿用配置基础价格的一半，向下取整。

## 编辑入口

`Assets/Resources/Menus/Shop.prefab` 为独立商店预制体，界面位置与尺寸均可在编辑器调整。`FlowShopWindow` 负责展示与选择状态，交易仍调用 RunController，不直接修改货币或库存。

`Tools > SpringUp > Flow > Build Shop UI` 显式重建商店默认布局，会覆盖该预制体的手动排版。它只在 Backpack 的导入元数据中新增 `ShopSlot` 和 `ShopCrown` 两个切片，保留原背包切片及 PNG。按钮采用纯色和细边框，不使用 Button.png。

## 轻量验收

`SpringUp.EditorChecks.ShopUiChecks.RunBatch` 检查购买、售卖、重复点击、重开售出状态、付费刷新、背包分页及余额不足；输出 1440×900、1280×720 的截图到 `Logs/ShopUI`。不需要执行整套游戏流程测试。
