# 器官执行器统一模板（当前实现）

更新：2026-10-17。沿用原文件名以保留链接；内容已从“准备怎么做”整理为“现在怎么用”。19 种执行器已统一配置结构，其中原 Hand 的六种使用 DirectActuatorConfig，弹体/区域/召唤类的 13 种沿用已实现的可调样板，参数和具体玩法见 [调参手册第 8 节](开发改动总览与调参手册.md#8-新器官的具体文件与参数)。

## 先理解四种对象

- **配置 `.asset`**：定义器官名称、ID、伤害、弹道等可调数值；多件同种器官共用它。
- **OrganDefinition**：启动时从配置生成的只读参数快照。
- **OrganInstance**：其中一件器官的独立身份；装到哪一槽由库存决定。
- **一次执行对象**：一发子弹、一片毒雾等的当前位置、计时和命中状态。不要把这些写回配置资产。

普通器官可装头、手、腿；躯干专用。自动管道负责“何时出手”，执行器负责“产生什么效果”。静止充能触发器与大激光蓄力是各自的局部规则；不再存在玩家攻击充能或 F 键调度。

因此不必给每个器官都创建一套 MonoBehaviour。已有 Pattern 能表达的器官，优先创建/调整配置；新玩法确实需要新状态机时，再增加执行类。

## 真实脚本样例：直线子弹配置

以下是本轮整理时的实际源码，不是另一套待实现接口：

```csharp
using System;
using UnityEngine;

namespace SpringUp.Organs
{
    [CreateAssetMenu(menuName = "SpringUp/Actuators/Straight Projectile")]
    public sealed class StraightProjectileConfig : OrganActuatorConfig
    {
        [SerializeField, Min(.01f), Tooltip("飞行速度，世界单位/秒；样板初值，可调整。")]
        private float speed = 8f;
        [SerializeField, Min(.01f), Tooltip("子弹碰撞半径，表现尺寸随之变化。")]
        private float hitRadius = .12f;
        [SerializeField, Min(.01f), Tooltip("未命中时最多存在多少秒。")]
        private float lifetime = 2f;

        protected override OrganDefinition CreateDefinition()
        {
            if (Damage <= 0f) throw new ArgumentOutOfRangeException(nameof(Damage));
            return new OrganDefinition(OrganId, DisplayName, OrganType.Actuator, Damage,
                chargeCost: ChargeCost, projectile: new StraightProjectileSettings(speed, hitRadius, lifetime));
        }
    }

    public class StraightProjectileSettings
    {
        public float Speed { get; }
        public float HitRadius { get; }
        public float Lifetime { get; }
        public StraightProjectileSettings(float speed, float hitRadius, float lifetime)
        {
            Validate(speed, nameof(speed)); Validate(hitRadius, nameof(hitRadius)); Validate(lifetime, nameof(lifetime));
            Speed = speed; HitRadius = hitRadius; Lifetime = lifetime;
        }
        private static void Validate(float value, string name)
        { if (float.IsNaN(value) || float.IsInfinity(value) || value <= 0) throw new ArgumentOutOfRangeException(name); }
    }
}
```

`chargeCost: ChargeCost` 是旧资产兼容参数，已在 Inspector 隐藏，自动攻击不依赖该数值。`speed`、`hitRadius`、`lifetime` 等才是这个弹体的实际参数。

## 一次执行怎样连接起来

管道轮到槽位 → 取配置快照与目标 → Runner 创建执行对象 → Tick 推进效果 → World 查询碰撞/结算伤害 → 上报开始、命中和结束事件 → 触发器可能追加发动后续执行器。

直线弹体朝发射时最近的有效敌人飞行，不继续转向；命中首个敌人后伤害并消失，碰墙消失，寿命到期消失。环绕、毒雾、召唤物可无目标发动；需要目标的器官本次找不到目标则等待后续循环。

换波、死亡、重开、实验室重置时需取消执行并清理表现。来源 InstanceId、槽位、目标 TargetId 和 CastContext 要沿用，防止对象池复用后误伤新敌人或连锁无限循环。

## 新增一件器官的步骤

1. 先判断现有 Pattern 是否足够；足够时创建独立配置资源，设唯一 Organ Id 与可读 Display Name。
2. 将配置加入 `OrganCatalog.asset`，让预览和实战都从同一个目录读取。
3. 若需进入正式库存，给 `organs.json` 增加匹配的 ID、类型和经济信息；需要正式掉落时再修改 `waves.json`。不要复制战斗数值为另一套权威来源。
4. 新执行类需同时支持战场与预览的 World 接口、自然结束与取消、来源记录及实际伤害事件。
5. 运行配置检查与相关效果测试，再在休息期试装，验证下一波、重开和清理。
