# 躯干器官实现与验收

2026-10-16。策划新增清单的 7 种躯干器官均已接入功能样板；本轮使用用户确认的含义与临时数值，后续可统一调整。

## 试用

运行 `SpringUpDemo`，休息期使用 **Tools → SpringUp → 样板 → 休息期添加全部躯干**。当前有两个躯干槽，7 种样板各添加一件；普通槽位不能装备躯干，战斗期间不能改装。出战前仍需满足未装备容量限制，样板尚未加入正式掉落表。

`LaboratoryDemo` 同样提供样例。装备后可观察伤害、回复、生命上限、触发频率和受伤无敌时间；移动、转向与相机实际变化请在战场体验。预览目标固定、角色朝向默认为右；必定暴击开关不改变实战暴击率。

参数资源：`Assets/Data/Organs/Torso/*Torso.asset`；相邻同名资源用于关联器官配置。界面的效果描述由当前数值生成，修改数值后重新进入 Play。

## 七种样板

1. **过载躯干**：伤害、概率、触发频率各 ×1.2；最大生命 ×0.6。
2. **共生躯干**：伤害 ×0.8；所有实际伤害附带 5% 吸血。
3. **冲锋躯干**：正前方 ±45° 内的目标受到伤害 ×1.6；移动速度 ×2、转向速度 ×0.6；移动沿转向后的角色朝向，而不是立即转向输入方向。
4. **远视躯干**：视野范围 ×1.2。
5. **聚焦躯干**：视野范围 ×0.8；伤害 ×1.2。
6. **长庇护躯干**：受伤无敌时间 ×1.5；受到伤害 ×1.2。
7. **短庇护躯干**：受伤无敌时间 ×0.5；受到伤害 ×0.6。

名称为方便区分的样板名，未替代策划的最终命名。

## 具体口径

- “基础触发效能”暂指伤害，包括直接攻击、持续区域伤害和流血；不放大弹体速度、范围、生命、吸血率、状态持续时间或召唤物属性。
- “概率”影响新触发器的概率、执行器施加状态的概率和角色已有暴击率，上限为 100%；0% 暴击不会凭空获得暴击。
- “频率 ×1.2”表示计时触发等待时间除以 1.2、静止充能速率乘以 1.2；也作用于槽位步进和实战及预览的整轮间隔。不会缩短大激光蓄力、弹体寿命、毒雾伤害间隔、受伤无敌时间或改变 10 杀门槛；2026-10-16 已取消玩家主动攻击充能，恢复自动循环。
- 前方判定使用**结算时玩家朝向及目标位置**，边界包含在内。正交相机的半高按视野倍率缩放，同窗口比例下可见宽、高同比变化；相机继续使用已有地图边界限制。
- 原代码没有统一的受伤无敌计时。本轮增加 `PlayerRuntime` 的 `baseInvulnerabilityDuration`，默认 **0.3 秒**；长/短庇护分别为 0.45/0.15 秒。敌人攻击统一走 `ReceiveAttack`，零实际伤害不产生无敌；暂停时计时停止，每波开始清除剩余无敌。底层 `TakeDamage` 仍可直接扣血，供调试与不受攻击无敌影响的伤害使用。
- 多个躯干倍率相乘；每个吸血来源的比例相加，上限 100%。共生躯干吸血与吸血针自己的吸血分别结算，均按实际扣血量计算、受生命上限限制，并保留原攻击链，防止回复触发无限循环。
- 装卸从当前配置重新计算，不做累积增减。生命上限降低会立即夹住当前生命；上限恢复不补血。属性夹取不算受伤/回复，不发动对应触发器。移速、转向、视野、频率等拆下后恢复其原有属性来源的值。
- 实验室使用独立预览生命和模拟受伤，不会损伤实际角色。视野/移动以实战为准；预览状态栏展示倍率。
