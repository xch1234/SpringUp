# 战斗 HUD 配置说明

战斗和休整区共用同一套 HUD 参数。波次、剩余时间、红色血条默认从上到下排列在右上角；骨髓位于装备栏下方，并随装备栏位置、大小变化自动跟随。获取骨髓时的奖励动画也会飞向新的骨髓位置。左下角保留操作提示。

## 打开调参工具

Unity 顶部菜单选择 **Tools → SpringUp → 战斗界面 → 编辑 HUD 布局与文字**，在 Inspector 中展开对应项目即可修改。也可以直接选择 `Assets/Resources/BattleHudSettings.asset`。

从 `Assets/Scenes/Flow/Bootstrap.unity` 开始运行，进入战斗或休整区后修改资源参数，可以立即查看效果；编辑器暂停时也能调整。修改的是配置资源，退出 Play 后仍会保留，完成后使用 **File → Save Project** 保存到磁盘。不要改运行时生成的 `Battle HUD` 子物体，它们的属性会被配置覆盖。

## 每一项可独立修改的参数

- **显示此项**：单独开关波次、时间、血量、骨髓或操作提示。
- **定位锚点**：屏幕四角、中心或装备栏左下沿。
- **位置偏移**：X 正数向右、Y 正数向上。右上角的默认偏移为负数，表示向屏幕内侧移动；装备栏下沿使用负 Y 表示向下留间距。
- **文字框尺寸**：宽和高；文字较长或需要换行时应增大尺寸，超出框的文字会被裁切。
- **整体缩放**：同时缩放文字和底板，范围 0.25–4。
- **字体大小**：范围 8–96。
- **不透明度**：0 完全透明、1 完全显示，作用于整项；如果只想隐藏底板，将底板颜色的 A 设置为 0。
- **文字颜色、底板颜色、文字对齐、加粗、描边**：控制外观和可读性。
- **显示文字 / 模板**：自由修改标签文字、标点或换行，动态数字用下方占位符保留。

位置和尺寸采用 Canvas 参考分辨率 1440×900 的单位，随窗口缩放。将项目移出屏幕或把文字框设得过小会影响显示；可以使用底部的 **恢复默认 HUD 布局与文字** 按钮恢复所有 HUD 参数，支持 Undo。

例如将骨髓偏移改为 `(20, -24)`，表示相对装备栏左下沿向右 20、向下 24；将不透明度设为 `0.6` 可得到半透明效果。

## 动态文字

- `{wave}`：当前波次；`{maxWave}`：总波数。
- `{time}`：剩余时间，格式为分:秒；`{seconds}`：剩余总秒数（向上取整）。
- `{health}`：当前生命；`{maxHealth}`：最大生命。
- `{marrow}`：当前骨髓数量。

例如：`第 {wave} 波 / 共 {maxWave} 波`、`倒计时 {time}`、`HP {health}/{maxHealth}`、`资源：{marrow}`。文字中可直接换行；未知占位符原样显示。不支持富文本标签。

默认打开背包、暂停菜单等窗口时隐藏 HUD，可通过顶部 **打开背包 / 菜单时隐藏** 修改。波次、时间、血条、骨髓和操作提示在战斗与休整区共用相同位置、尺寸、透明度、颜色和文字模板。休整区没有倒计时，`{time}` 显示“休整中”，`{seconds}` 为 0；返回战斗恢复倒计时。操作提示支持 `{interaction}`，靠近商店或实验室时显示当前交互按键提示（默认 E），战斗中为空；`{inventoryKey}` 显示当前背包按键与 Tab（默认 B / Tab）。在设置菜单改键后，两种提示会同步更新。原顶部整行状态信息已由这套 HUD 替代。

## 红色血条

红色填充长度 = 当前生命 / 最大生命，受伤时缩短，回血时增长，下一波恢复满血后重新填满。空缺部分使用深红色底色，血量文字覆盖在血条上。

展开 **红色血条**，可调整位置、血条宽高、整体缩放、透明度及原有文字参数。另外可以修改 **血条填充颜色**、**已损失血量区域颜色**、**血条内边距**；取消 **显示血量文字** 可以仅显示血条。修改血条整体透明度会同时影响填充、底色和文字。

## 装备栏

同一配置工具中的 **装备栏（战斗与休整通用）** 提供显示开关、屏幕锚点、位置偏移、宽高、整体缩放、不透明度。默认左上角、偏移 `(16, -65)`、尺寸 `530×265`、缩放 `1`。

**自由更换装备栏图片**：将新图片放进项目，在图片 Inspector 中设置 **Texture Type = Sprite (2D and UI)**，点击 Apply。然后将 Sprite 拖入本工具的 **装备栏图片（留空使用原图）**。运行中立即更新，战斗和休整共用；清空该字段（None）即可恢复预制体原图 `Assets/Art/UI/HUD.png`。完成后使用 **File → Save Project** 保存配置。

此选项替换装备栏整张底图（包括图片中绘制的边框和部位标题），器官图标与实际槽位保持原有功能和相对位置。新图片会铺满装备栏，建议使用与原图相同的宽高比例和槽位布局；若把槽位画到新位置，实际器官图标不会自动识别并移动。

**底板颜色（A 控制底图透明度）**：为默认或自定义装备栏底图调色，颜色与图片原色相乘；默认白色保留原图颜色。A 为 0 时隐藏底图、为 1 时完整显示，不影响独立的器官图标。最终底图透明度还会乘以装备栏整体不透明度。支持运行中实时修改。

- 保持原比例放大或缩小，使用 **整体缩放**，例如 `0.8` 表示原来的 80%。
- 单独修改宽高会拉伸整套界面；边框、槽位和图标一起变化，保持位置对齐。
- **不透明度** 作用于装备栏整体；设为 0 时也不会拦截鼠标操作。
- 骨髓使用“装备栏左下沿”锚点时自动跟随新位置和尺寸；隐藏装备栏不会同时隐藏骨髓，它仍按装备栏的布局定位。
- 战斗和休整共用这套装备栏设置。打开背包等窗口时装备栏始终隐藏，避免遮挡窗口；顶部隐藏开关控制两个场景的数据 HUD。

参数支持运行中实时预览并保留到退出 Play 后。装备栏内的部位标题属于现有图片素材，修改这些文字需要更换素材。
