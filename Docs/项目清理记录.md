## 为什么这些文件仍保留

- **四个场景**：SpringUpDemo 用于完整试玩；LaboratoryDemo 用于独立预览；OrganDemo 用于旧器官演示和回归；Battle_Greybox 是程序 C 的源场景和同步来源。
- **Resources 下的敌人、弹体和目录**：由代码动态加载，不能只查场景引用。
- **Battle_Greybox.generated.txt**：生成器读取的结构版本标记。删掉可能使灰盒在编辑器启动时重建。
- **BattleRunDriver / BattleRunLink**：仍为独立灰盒提供调试流程；主场景不安装它们。
- **测试、检查、构建、场景同步与配置编辑器脚本**：由菜单、测试入口或 Unity 自动调用，不需要场景引用。
- **URP 模板、渲染与输入配置**：仍用于新建场景、渲染或输入设置。
- **开发日志及配图**：是用户要求保留的发布资料；此次未改动。历史设计资料用于追溯，不列入日常操作入口。
- **Library / Temp / Logs / UserSettings**：编辑器缓存、验证副本、日志和本机设置，不属于弃用源码；已被 Git 忽略，本次不清空运行环境。
