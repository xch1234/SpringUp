# 菜单与设置界面

运行入口：`Assets/Scenes/Flow/Bootstrap.unity`。

## 界面调整

- `Assets/Resources/Menus/MainMenu.prefab`：背景和开始游戏、设置、退出三个按钮。更换背景时修改 `Backdrop` 的 Image / Source Image。
- `Assets/Resources/Menus/Pause.prefab`：完整 ESC 素材等比居中，按钮点击区域与图内三个按钮对齐。世界覆盖 60% 黑色遮罩。
- `Assets/Resources/Menus/Settings.prefab`：同页音量和键盘绑定，左文字、右控件。
- `MenuSettingsView` 的 Panel、Design Size 和 Screen Height Fraction 控制面板尺寸及小屏适配；暂停面板包括素材透明留边，因此实际可见高度约为屏幕的 68%。
- 主菜单和设置使用 Button、Backdrop 的导入切片及九宫格边框，去除素材的黑色外围留边。原始 PNG 不改动。
- 日常直接编辑上述预制体。`Tools > SpringUp > Flow > Rebuild Menu UI` 会重建这三个预制体并覆盖手工布局，仅在明确需要重建时使用。

## 设置与操作

音乐、音效分别实时调节，百分比显示，0% 静音。音效调节播放当前受击音效试听。设置使用本机 PlayerPrefs 的 `SpringUp.Settings.v1` 保存，切场景、退出重开后仍有效。音乐默认 55%，音效默认 85%。

可改键：上/下/左/右移动、疾跑、交互、背包。点击对应按钮后按新键；冲突或保留键会提示并保留原绑定。现有移动动作通过运行时绑定覆盖实现，不修改输入资产的默认绑定。

方向键固定作为移动备用键，Tab 固定作为背包备用键；它们以及 Esc 不可用于其他绑定。Esc / 鼠标右键取消改键。按键提示读取实际绑定；将来删除提示不会影响输入逻辑。

鼠标右键逐层返回：设置返回来源页面，暂停返回游戏，背包/商店/实验室关闭，放弃确认取消。拖动中先取消拖动，本次不关闭窗口。世界中无菜单时、主菜单、结算和加载期间右键不执行退出或跳过。

恢复默认只重置音量和按键，不更改本局数据。主菜单退出直接关闭独立运行的游戏；编辑器内则停止 Play。返回主菜单仍需确认放弃本局。

## 验证

`SpringUp.EditorChecks.MenuSettingsChecks.RunBatch` 在 Unity batchmode 中运行（不要添加 `-quit`），检查偏好保存、冲突/保留键、改键取消、运行时移动、背包与实验室交互、右键返回和拖动取消、嵌套暂停，并在 `Logs/Presentation/menu-*.png` 输出界面截图。

截图覆盖 1440×900、1920×1080、1280×720；自动检查控件未超出屏幕。`MenuSettingsTests` 提供可单独运行的 EditMode 检查。测试会恢复测试前的本机设置。

声音听感和独立程序实际退出仍需在最终打包试玩时人工确认。
