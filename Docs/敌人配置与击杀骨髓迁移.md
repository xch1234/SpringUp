# 敌人配置与击杀骨髓迁移（2026-10-17）

> 后续规则更新：波末额外保底、击杀器官奖励、无限库存和独立飞行光点见 [第二阶段说明](第二阶段奖励与光点说明.md)。以下保留第一阶段迁移历史。

正式入口仍为 Bootstrap → Battle → Rest。本记录中的规则优先于旧策划案；不重平衡敌人，不改第七波玩法。

## 调参

停止 Play 后在 Inspector 修改 `Assets/Data/Enemies/*.asset`：身份、档次、常规刷怪开关、基础骨髓、生命、速度、伤害、冷却、移动距离、远程/接触攻击、治疗、产兵和位移规则均在这里。Prefab 只保留配置引用、外观、碰撞与组件装配。运行血量、计时器、死亡标记仍在实例上。

- `EnemyCatalog.asset` 引用七种敌人；`marrowVisualLifetime` 默认为 0.3 秒。骨髓方块只有表现，无碰撞或拾取判定。
- `TrainingDummy.asset` 是休息区原有训练目标的独立变体，保留 10000 生命；`Dummy.asset` 保留战场木桩 99999 生命。两者类型均为 Dummy、不可常规刷怪、零收益。
- `Assets/Resources/EnemyCatalogReference.asset` 仅持有目录与波次设置引用，让 Assets/Data 资源作为依赖进入构建；运行时用 Resources 加载，不依赖 UnityEditor。
- `Assets/Data/Waves/SpawnSettings.asset` 的 `firstSixSpawnSeconds` 默认为 50，前六波在前 50 秒完成原计划数量，60 秒结束。波次数量/组成未迁入敌人配置。
- 第七波仍为 60 秒、计划 1 个 Normal，在原有 60 秒时间点生成，然后按原规则计时结束；没有增加 Boss。通用提前生成仅对 1–6 波生效。
- 基础收益：Normal 30、Fast 30、RangedKeeper 40、RangedChaser 50、Arsenal 80、Medic 60、Dummy 0，仅为调试值。

## 迁移核对

正式刷怪加载 Resources/Enemies 中的 Prefab，没有发现运行代码覆盖这些基础值。因此采用 Prefab，而不是旧 EnemyArchetypeConfig 代码表。

| 敌人 | 采用生命（旧代码表） | 采用攻击（旧代码表） | 移速 |
|---|---|---|---|
| Normal | 20（20） | 5（5） | 2.5 |
| Fast | 14（15） | 5（4） | 3.25 |
| RangedKeeper | 20（15） | 5（4） | 2 |
| RangedChaser | 24（20） | 5（3） | 2.5 |
| Arsenal | 40（30） | 5（0） | 0 |
| Medic | 16（15） | 5（0） | 2.75 |
| Dummy | 99999（99999） | 0（0） | 0 |

Arsenal 和 Medic 不装配攻击能力，保留攻击字段 5 不代表它们开始攻击。七种 Prefab 的射程均为 6、弹速 4、冷却 1.5；保留原值。Keeper 保持距离 6，其余为 5。

兵工厂保持原判断 `ActiveCount >= maxAliveProducts + 1`：默认配置 12，即全场活跃敌人数达到 13 时暂停。全场所有类型、所有工厂都参与计数；不是每座工厂独立上限，也没有累计产兵限制。产兵仍为 Normal，收益读取同一份 Normal 配置。

灰盒兜底统一为 Normal 的行为与数值；旧兜底自带的远程攻击被配置关闭，避免资源缺失时变成另一套普通敌人。生成器也改为引用定义，不再写入第二套数值。

## 入账与生命周期

致死伤害先锁定本次生命，再通过 DeathCommitted 快照立即结算，随后保留原 Damaged/Killed 事件供器官触发。金额和出生 ID 不从回池后的对象读取。RunController 按出生 ID 防重复，使用 decimal 余量累计装备倍率；没有 ±5% 随机收益，没有等待特效的待到账余额。

清场、停用、卸载不触发入账。波末移除残存敌人和表现物；波末只发器官，不再增加固定骨髓。旧 MarrowDelta 展示改为本波击杀已入账统计，不作第二次付款。出售与购买逻辑保留，收集网说明已更新。正式 HUD 持续读取余额，旧 Demo 也连接同一套击杀入账并在销毁时解绑。
