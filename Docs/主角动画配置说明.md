# 主角动画

主角已接入 `Assets/Art/Characters/1709.png` 的 12 张精灵帧：上排 `1709_0`～`1709_5` 朝右，下排 `1709_6`～`1709_11` 朝左，各按从左到右的顺序循环。

从 `Assets/Scenes/Flow/Bootstrap.unity` 开始游戏，战斗和休整区的 Player 都会自动使用新外观。左右移动切换朝向，上下移动和停下保留上一次朝向。移动时默认每秒 10 帧，疾跑播放速度乘 1.5，待机时以每秒 4 帧缓慢循环。暂停菜单、背包和实验室打开时动画暂停。

通过 **Tools → SpringUp → 主角 → 编辑主角动画** 打开 `Assets/Resources/PlayerAnimationSettings.asset`，可修改左右帧序列、移动/待机帧率、疾跑动画倍率、整帧高度、显示偏移及初始朝向。待机帧率设为 0 可停在当前方向的第一帧。大小和播放速度支持运行时调节；初始朝向在下一次创建 Player 时生效。

整帧高度默认 1.5 世界单位，包含透明留白。动画配置只调整外观；主角碰撞框现为 0.65×0.65 世界单位，集中在身体中心，转向时也比贴图窄。移动属性和器官攻击方向保持原逻辑。角色图像保持直立，受击闪红会跟随当前动画帧。

保留原有 362×362 切片、文件 GUID 和子精灵引用；采用 Point 过滤、无压缩和 4096 最大尺寸，避免原图宽 2172 像素被缩小。新增动画无需重建场景，运行时可在 Player 下找到 `Player Animated Visual`。
