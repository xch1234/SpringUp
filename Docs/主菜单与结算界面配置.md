# 主菜单与结算界面配置

Unity 菜单：**Tools → SpringUp → 主菜单与结算 → 编辑图片、布局和提示**。
配置资源：`Assets/Resources/MenuPresentationSettings.asset`。从 Bootstrap 运行后可实时调节，点击 Inspector 底部“保存配置”保存；不影响战斗地图、HUD、器官参数。

## 主菜单

- 默认图片为 `Assets/Art/UI/封面.png`，完整等比显示。整个游戏统一采用封面原图的 **1448×1086（4:3）** 显示区域，主菜单、战斗、休整、HUD、弹窗和结算保持一致。
- 默认桌面分辨率为 1448×1086；全屏或 Game 窗口比例不同会等比适配：宽屏左右黑边，较窄窗口上下黑边。画面不会拉伸，黑边不属于可点击的游戏区域。“屏幕底色”仅控制游戏区域内封面背后的颜色。
- “封面”可设置 Sprite、位置、尺寸、颜色、透明度和保持比例；“整体缩放”同时缩放图片及点击区域。
- 图片自带“开始游戏／退出游戏／设置”字样，程序使用透明点击区，不重复绘制文字。
- 三个点击区分别配置中心和尺寸。坐标以封面中心为原点，X 向右、Y 向上，默认参考尺寸为 1448×1086。换图或改封面尺寸后，按新图重新对齐点击区。
- 打开“显示点击区域”显示绿色区域；完成调整后关闭。可单独调整鼠标悬停/键盘选中的颜色及透明度。
- 图片中已经画好的文字不能通过字符串参数修改，需要替换图片。

## 结算

- 背景默认使用 `背景.png`。可换图、设置透明度、颜色、偏移与尺寸；默认等比铺满并裁切边缘，取消“背景铺满”则完整显示。
- 失败与胜利分别使用 `battle-fail.png` 和 `battle-victory.png`，各自可配置图片、位置、尺寸、颜色、透明度和保持比例。
- 窗口位置以屏幕中心为原点，默认参考尺寸 1440×900；窗口和提示一起随分辨率等比缩放。
- 提示默认“点击任意位置返回标题”。可修改文字、字体、字号、颜色、文字框底色、尺寸、位置偏移、闪烁开关、周期及最低/最高透明度。
- 提示位置偏移相对于当前胜败窗口下边缘中心。Y 为负数表示向下，默认 -70。
- 结算期间游戏暂停，但文字使用真实时间闪烁。点击画面任意位置直接返回主菜单，无需确认。
- “结算防误触时间”默认 0.35 秒；结算出现前已经按住的鼠标不会直接关闭结算，需要松开后重新点击。

替换图片时，导入设置应为 **Sprite (2D and UI)**。如果图片是 Multiple 模式，展开图片后拖入对应 Sprite。四张原始图片及已有切片不作修改。

## 设置窗口与调试界面

设置窗口已放大为 1100×1000 参考尺寸，标题 44 号，主要标签和按键文字 30～32 号，底部说明 24 号。窗口按可用画面自动缩放。

战斗和休整区左下角操作提示默认隐藏。右下角调试面板默认关闭，可在 **Tools → SpringUp → 战斗界面 → 编辑 HUD 布局与文字** 勾选“显示右下角调试面板”，运行中立即生效。对应资源是 `Assets/Resources/BattleHudSettings.asset` 的 `showDebugPanel`。

关闭调试面板后，休整区保留独立的“进入下一波”按钮；Esc 暂停、背包和商店／实验室交互仍可正常使用。需要重新显示左下角文字时，在同一工具中展开“操作提示”，开启其显示开关。
